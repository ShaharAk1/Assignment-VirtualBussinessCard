# Virtual Business Card

A digital business card for Shahar Akiva - a single-page, responsive site built with plain HTML, CSS, and no JavaScript dependencies. Created as **Assignment 1** for the Web Application Programming course.

**Live demo:** https://shaharak1.github.io/Assignment-VirtualBussinessCard/

## Features

- **Profile header** — photo, name, and title alongside a contact list (email, phone, LinkedIn, GitHub) with icons.
- **Bio section** — a short personal/professional summary.
- **Projects grid** — cards linking out to featured projects (ChessWeb, PTM Project) plus a summary of work done during military service.
- **Light/dark mode toggle** — a checkbox-driven theme switch (no JS) with a sun/moon icon, animated on hover, using CSS custom properties for theming.
- **Responsive layout** — the profile section and project grid reflow into a single column on narrow screens.
